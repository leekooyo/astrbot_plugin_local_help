# 本地帮助

**当前版本：v1.1.0。** 元数据声明需要 AstrBot 4.17.0 或更高版本。

## 安装与维护

本插件由 leekooyo 维护，可通过仓库地址 `https://github.com/leekooyo/astrbot_plugin_local_help` 安装；当前本机部署目录为 `data/plugins/astrbot_plugin_local_help`。插件配置由 AstrBot 单独保存在 `data/config/astrbot_plugin_local_help_config.json`；更新插件文件时保留这份配置即可继续使用已有简称和模型设置。

- `/help`、`/helps`、`/帮助`、`/菜单`：显示所有已加载插件的简短名称，一张图片。
- `/help <插件名>`：显示当前用户可用的常用指令，一张图片。
- `/help <插件名> 高级`：显示当前用户可用的其余指令，一张长图。
- `/help 归类 <插件名>`：仅机器人管理员可用，使用配置的大模型重新划分该插件的常用与高级指令，并立即保存结果。
- 插件原显示名与插件标识仍可用于查询。

在插件配置的“插件简称”列表中，按 `插件标识:简称` 添加或修改名称。新装插件会自动出现在目录中；未设置简称时使用插件原显示名。简称配置保存在 AstrBot 的 `data/config/astrbot_plugin_local_help_config.json`，与插件代码分开。

默认简称列表覆盖此维护集合中的 12 个插件；`astrbot_plugin_status` 尚无预设简称，安装后会显示原名，可按上文方法手动添加。在其他安装环境中，这些名称仅对实际已加载的插件生效。目录只显示插件名，不加指令前缀。现有插件的常用指令由本插件预设；新插件默认全部放在常用帮助中。管理员可以随时手动归类。插件版本或指令清单变化后，旧分类失效，全部指令回到常用帮助，直到再次手动归类。

“帮助归类模型 ID”配置项默认留空，留空时使用当前会话模型。只有收到 `/help 归类 <插件名>` 才会调用模型；普通帮助查询不调用。模型只负责把已注册的指令名分组，输出有遗漏、重复或新造指令时不保存。归类失败后可再次手动触发，原有帮助仍可查看。

帮助图读取当前已注册的指令、别名和权限，并对部分插件内部权限作补充判断。群聊专用命令会标注使用场景；实际执行仍由各插件自身检查权限和业务条件。图片生成失败时会返回文字错误提示。

对自行解析消息的指令，帮助图补充了实际需要输入的参数；引用消息或图片这类操作以前置提示表示，不写成可输入的参数。B站总结指令缺少源码说明时，使用本地简短说明。详情图不显示内部插件标识；管理员仍可在插件配置中查看标识并设置简称。

## 新安装一个插件后

1. 在 AstrBot 的插件市场安装，或上传插件压缩包；确认插件显示为已加载。
2. 在私聊发送 `/help`。新插件会以原显示名出现在目录里，无需修改本地帮助插件。
3. 如果名称太长，到“本地帮助”的插件配置中，在“插件简称”列表新增一行 `插件标识:简称` 并保存。例如 `new_plugin:新功能`。保存配置后，AstrBot 会重载本地帮助插件。
4. 再发送 `/help` 检查简称，发送 `/help 新功能` 查看指令。若常用图太长，管理员发送 `/help 归类 新功能`，完成后用 `/help 新功能 高级` 查看被归入高级的指令。原显示名和插件标识也能查询。

插件升级后，只要插件标识不变，已有简称会保留。若插件改了标识，需把简称配置中的旧标识改为新标识。若新插件没有注册手动指令，详情图会直接说明。

本插件使用 AstrBot 当前配置的默认图片模板。它以较高优先级处理 `/help` 并停止后续处理，避免与内置 `/help` 重复回复。若停用本插件，内置 `/help` 仍可用。
